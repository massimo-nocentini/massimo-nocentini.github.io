The (aux anthropic) module

The Anthropic Messages API, offline

 Posted on October 21, 2026  |   80 min  |   Massimo Nocentini

Talking to Claude from CHICKEN Scheme

Every case below is offline. There is no network and no API key: the HTTP transport is the parameter anthropic/transport, and each case installs a stub that replays a recorded response and records the exact bytes the module tried to send. The live suite is test/anthropic-live.scm and is not part of make test.

The transport contract is four arguments in and one anthropic-wire record out:

(transport url headers body stream?) -> anthropic-wire
  status   exact-integer HTTP status
  headers  ((lowercase-name value) ...)
  origin   a datum identifying what produced this wire
  port     an input port at the first byte of the body; it MUST answer read-string
           correctly, so a custom make-input-port needs a read-bytevector: hook
  close    thunk -> (values exit-status diagnostics); idempotence is enforced by
           anthropic-wire/close!, which memoises the thunk's values, not by a backend

Two facts about the JSON layer drive most of the request cases. The encoder writes '() as {} and only #() as [], so every JSON array on the wire is a Scheme vector; and it escapes C0 control characters as \u00XX, where ->string/json used to emit CHICKEN's \x01; -- not JSON, and a body this parser refuses.

Nothing is ever handed to simdjson without passing anthropic-json/well-formed? first: (aux simdjson) signals a malformed document as a plain Scheme error, and the gate is what makes every malformed body an anthropic-decode-error.

  (define (anthropic-json/emit v port)
    (cond ((string? v) (anthropic-json/escape v port))
          ((boolean? v) (display (if v "true" "false") port))
          ((void? v) (display "null" port))
          ((null? v) (display "{}" port))
          ((symbol? v) (anthropic-json/escape (symbol->string v) port))
          ((char? v) (anthropic-json/escape (string v) port))
          ((number? v)
           (cond ((and (exact? v) (integer? v)) (display v port))
                 ((and (exact? v) (rational? v))
                  (display
                    (anthropic-json/flonum->string (exact->inexact v))
                    port))
                 ((and (flonum? v) (= v v) (< -∞ v ∞))
                  (display (anthropic-json/flonum->string v) port))
                 (else (anthropic-raise/encode "not a finite JSON number" v))))
          ((vector? v)
           (display "[" port)
           (let1 (n (vector-length v))
                 (let L ((i 0))
                   (when (< i n)
                         (when (> i 0) (display "," port))
                         (anthropic-json/emit (vector-ref v i) port)
                         (L (add1 i)))))
           (display "]" port))
          ((pair? v)
           (display "{" port)
           (let L ((lst v) (first? #t))
             (when (pair? lst)
                   (unless first? (display "," port))
                   (let1 (kv (car lst))
                         (unless
                           (and (pair? kv) (pair? (cdr kv)) (null? (cddr kv)))
                           (anthropic-raise/encode
                             "a JSON object entry must be a two-element list"
                             kv))
                         (let1 (key (car kv))
                               (cond ((symbol? key)
                                      (anthropic-json/escape (symbol->string key) port))
                                     ((string? key) (anthropic-json/escape key port))
                                     (else
                                      (anthropic-raise/encode
                                        "a JSON object key must be a symbol or a string"
                                        kv))))
                         (display ":" port)
                         (anthropic-json/emit (cadr kv) port))
                   (L (cdr lst) #f)))
           (display "}" port))
          (else (anthropic-raise/encode "cannot be represented as JSON" v))))
