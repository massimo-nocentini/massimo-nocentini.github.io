# Releases

## Nvim 0.12.3 is out!

Fetch the [v0.12.3.tar.gz](https://github.com/neovim/neovim/archive/refs/tags/v0.12.3.tar.gz) tarball, extract and build with:

```zsh
make CMAKE_BUILD_TYPE=Release CMAKE_INSTALL_PREFIX=$HOME/.local/ install
```

according to the [build doc page](https://neovim.io/doc/build/).
