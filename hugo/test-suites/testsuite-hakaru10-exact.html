Exact oracles

Hakaru10 infers by Markov chain Monte Carlo, so its answers are estimates. To test them we need exact answers, and oracles that share as little code as possible with the engine they check. This page is about the oracles of (aux hakaru10 exact): exact enumeration, a reference evaluator, and the exact kernel of the 'extended semantics. None of them is in upstream: they are new in the port.

A model is a value of the State monad that threads the chain (Syntax.hs:82), written with do/monad: dist (an observation is the dist of a conditioned distribution), diracN and if_ are models, and running the model creates upstream's trace graph, node by node in bind order. The oracles do not run a model in a semantics of their own: they build it once, in 'extended mode, and walk the graph of that build (plan §6.10, C37). One build is the whole graph, because SExp is applicative, not a monad (Syntax.hs:118), and if_ builds both of its branches (Metropolis.hs:650-661). Exact enumeration visits the nodes in address order, which is their creation order, and builds a lazy search tree in the format of Embedded probabilistic domain-specific language HANSEI:

type 'a vc = V of 'a | C of (unit -> 'a pV) and 'a pV = (prob * 'a vc) list

in Scheme the list (((V v) p) ...) and (((C thunk) p) ...). A choice becomes one C entry per support point (x . p) with p > 0, whose thunk continues the walk with x. An observation becomes one entry weighted by its likelihood, or no entry at all when that likelihood is 0 or its LL is not finite (NaN, +inf; E6). The nodes of a branch that the values on the path leave inactive are skipped. A thunk may be forced in any order, so it first restores the node states of its own path. probcc-explore and probcc-normalize of (aux hansei) then explore and normalize the tree. Only Hansei's data-level tools are used: no oracle uses delimited control.

Enumeration and forward sampling share the graph and the node functions with the engine, but none of its incremental machinery: propagation, the update queue, the switch of branches, the delayed and pending updates, the journal and the acceptance ratio. So an exact posterior against an MH chain tests the kernel and the incremental update. The build checks the static discipline as it goes, such as observations external to the model or no node escaping its branch (H5). Continuous observations weigh by their density, which is right for posteriors over discrete choices. A continuous choice on a path the enumeration takes is a support error, and so are more paths than #:max-paths.

A model runs several times: once per oracle call, and once more for the rebuild of construction-check. So a Scheme effect that must happen once per run goes inside a bind (plan §15, C35). Pre-allocation with replicate/monad (H8), folds and traversals are all safe. One build stands for every build only if the model does not branch in plain Scheme on a node or on a value drawn while it is built. Nothing enforces that, and nothing catches a model that breaks it: the rebuild of construction-check (H2) draws the same values from a copy of the same source, so it takes the same branch. The rebuild catches only a construction that depends on state outliving a run, such as a counter (hakaru10.scm, case B4′).

The kernel residual (E10) checks the MH kernel itself, not one of its chains. In 'extended mode the inactive resampleable nodes are auxiliary variables with their prior. Over every assignment x of all resampleable nodes, inactive ones included, the target is π(x) ∝ exp L(x), where L sums the LLs of every resampleable node and of every active observed node. The one-step kernel T is computed exactly from the engine's own propagation and acceptance code: each active resampleable node is picked with probability 1/N(x), each support point v of its distribution is proposed with its probability q, and the forced step is accepted with probability min(1, eᵅ) and then rolled back. The residual is maxₓ |(πT)(x) − π(x)|, which is below 10⁻¹² when π is stationary for T. This is upstream's merged-node argument made exact (Metropolis.hs:1145-1168):

So, when it comes to computing the acceptance ratio for a program
with branches, we take

p4 = do
     c <- bernN (Val 0.5)
     if_ c (do e1 e2 ...)
           (do e3 e4 e5 ...)

to be

p4' = do
      c <- bernN (Val 0.5)
      if_ c e_then e_else

That is, we merge (at least for the purpose of presentation) e1, e2 ...
into one node e_then, whose ll is the sum of ll of constituents. Ditto
for e_else.

When we switch the branches, we remove the ll of one branch from
llcum and add ll of the other branch. In our terms, we remove the ll
of the deactivated nodes and add ll of the activated nodes.

This algorithm is resilient with respect to adding replacing a node e
with e >>= diracN -- the desired behavior.

In 'upstream mode the argument does not hold for resampleable nodes whose parameters change while they are inactive, as pswitch shows (E8; the main suite's hakaru10-semantics). 'extended mode is the fix, and E10 shows that it leaves the target invariant.

(module
  (aux hakaru10 exact)
  *
  (import
    scheme
    (chicken base)
    (only (chicken memory representation) record-instance? record->vector)
    (only srfi-1 filter-map count fold iota any)
    srfi-69
    (aux base)
    (only (aux hansei) probcc-τ probcc-unit probcc-explore probcc-normalize)
    (only (aux hakaru10 random) make-stdgen-source rng-source-copy)
    (aux hakaru10 distribution)
    (only (aux hakaru10 util) histogram-sort)
    (aux hakaru10 engine))
  (define (ll-close? a b #!optional (scale (abs a)))
    (or (= a b)
        (and (nan? a) (nan? b))
        (and (finite? a)
             (finite? b)
             (<= (abs (- a b)) (* 1e-09 (max 1.0 scale))))))
  (define (same-value? a b)
    (let1 (budget 100000)
          (define (spent?) (set! budget (sub1 budget)) (negative? budget))
          (let walk ((a a) (b b))
            (cond ((eq? a b) #t)
                  ((and (flonum? a) (flonum? b))
                   (or (eqv? a b) (and (nan? a) (nan? b))))
                  ((and (procedure? a) (procedure? b)) #t)
                  ((and (promise? a) (promise? b)) #t)
                  ((and (pair? a) (pair? b))
                   (or (spent?)
                       (and (walk (car a) (car b)) (walk (cdr a) (cdr b)))))
                  ((and (vector? a) (vector? b))
                   (and (= (vector-length a) (vector-length b))
                        (let loop ((i 0))
                          (or (= i (vector-length a))
                              (spent?)
                              (and (walk (vector-ref a i) (vector-ref b i))
                                   (loop (add1 i)))))))
                  ((or (deferred? a) (deferred? b)) (equal? a b))
                  ((and (record-instance? a) (record-instance? b))
                   (walk (record->vector a) (record->vector b)))
                  (else (equal? a b))))))
  (define (choice-support dk who)
    (or (distribution-support dk)
        (hakaru10-error
          'support
          who
          "a random choice without a finite support"
          dk)))
  (define (build model src semantics who)
    (build-chain (model->trace model who) src semantics))
  (define (static-graph model who)
    (let1 (src (make-stdgen-source 17))
          (let retry ((builds 1000))
            (if (zero? builds)
              (hakaru10-error
                'construction
                who
                "no complete build of the model in 1000 tries"
                model)
              (receive
                (ch result)
                (build model src 'extended who)
                (if result (values ch result) (retry (sub1 builds))))))))
  (define (walk-active! n)
    (let1 (k (scope-inactivity n)) (node-inactive-set! n k) (zero? k)))
  (define (branch-starts ch)
    (let1 (starts (make-vector (add1 (chain-count ch)) '()))
          (chain-fold
            (λ (n _)
               (when (eq? (node-role n) 'exit)
                     (let1 (b (node-branch n))
                           (for-each
                             (Λ ((,lo unquote hi) ,polarity)
                                (when (< lo hi)
                                      (vector-set!
                                        starts
                                        (add1 lo)
                                        (cons (list hi (branch-entry b) polarity)
                                              (vector-ref starts (add1 lo))))))
                             (list (branch-then-range b) (branch-else-range b))
                             '(#t #f)))))
            (void)
            ch)
          starts))
  (define (past-inactive-branches starts a)
    (let1 (hi (and (< a (vector-length starts))
                   (any (Λ ((,hi ,entry ,polarity))
                           (and (not (eq? (node-value entry) polarity)) hi))
                        (vector-ref starts a))))
          (if hi (past-inactive-branches starts (add1 hi)) a)))
  (define (graph->search-tree
           ch
           result
           #!key
           (max-paths #f)
           (who 'exact-posterior))
    (let ((last (chain-count ch))
          (now (chain-now ch))
          (starts (branch-starts ch))
          (paths 0))
      (define (restore! frame)
        (for-each
          (Λ ((,n unquote s)) (node-inactive-set! n 0) (node-state-set! n s))
          frame))
      (let walk ((a (past-inactive-branches starts 1)) (frame '()))
        (define (enter n s)
          (node-state-set! n s)
          (walk (past-inactive-branches starts (add1 a))
                (cons (cons n s) frame)))
        (if (> a last)
          (begin
            (add1! paths)
            (when (and max-paths (> paths max-paths))
                  (hakaru10-error
                    'support
                    who
                    "more paths than max-paths"
                    max-paths))
            (probcc-unit (force-value (node-value result))))
          (let1 (n (chain-node ch a))
                (cond ((not (walk-active! n))
                       (walk (past-inactive-branches starts (add1 a)) frame))
                      ((resampleable? n)
                       (filter-map
                         (Λ ((,x unquote p))
                            (and (positive? p)
                                 (probcc-τ
                                   p
                                   (restore! frame)
                                   (enter n (recomputed-state n now x)))))
                         (choice-support (node-distk n) who)))
                      ((eq? (node-kind n) 'observed)
                       (let* ((s (recomputed-state n now))
                              (w (exp (nstate-ll s))))
                         (if (or (not (finite? (nstate-ll s))) (zero? w))
                           '()
                           (list (probcc-τ w (restore! frame) (enter n s))))))
                      (else (enter n (recomputed-state n now)))))))))
  (define (model->search-tree model #!key (max-paths #f))
    (receive
      (ch result)
      (static-graph model 'model->search-tree)
      (graph->search-tree
        ch
        result
        #:max-paths
        max-paths
        #:who
        'model->search-tree)))
  (define (exact-posterior model #!key (max-paths #f))
    (receive
      (ch result)
      (static-graph model 'exact-posterior)
      (histogram-sort
        (map (Λ (((V ,v) ,p)) (cons v p))
             (probcc-normalize
               (probcc-explore
                 +inf.0
                 (graph->search-tree ch result #:max-paths max-paths)))))))
  (define (graph-forward ch result src #!optional (starts (branch-starts ch)))
    (let ((last (chain-count ch)) (now (chain-now ch)))
      (let walk ((a (past-inactive-branches starts 1)) (ll 0.0))
        (define (next) (past-inactive-branches starts (add1 a)))
        (if (> a last)
          (values (force-value (node-value result)) ll)
          (let1 (n (chain-node ch a))
                (cond ((not (walk-active! n)) (walk (next) ll))
                      ((memq (node-kind n) '(resampleable observed))
                       (receive
                         (x llx)
                         (distk-sample (node-distk n) src)
                         (node-state-set! n (recomputed-state n now x))
                         (walk (next) (if (resampleable? n) ll (+ ll llx)))))
                      (else
                       (node-state-set! n (recomputed-state n now))
                       (walk (next) ll))))))))
  (define (weighted-samples n model #!key (seed 17) (rng #f))
    (receive
      (ch result)
      (static-graph model 'weighted-samples)
      (let ((src (or rng (make-stdgen-source seed)))
            (starts (branch-starts ch)))
        (let loop ((i 0) (samples '()))
          (if (>= i n)
            (reverse samples)
            (receive
              (v ll)
              (graph-forward ch result src starts)
              (loop (add1 i) (cons (cons v ll) samples))))))))
  (define (likelihood-weighting n model #!key (seed 17) (rng #f))
    (let* ((samples
             (filter-map
               (Λ ((,v unquote ll)) (and (finite? ll) (cons v ll)))
               (weighted-samples n model #:seed seed #:rng rng)))
           (top (fold (λ (s m) (max (cdr s) m)) -inf.0 samples))
           (table (make-hash-table equal?)))
      (for-each
        (Λ ((,v unquote ll))
           (hash-table-update!/default
             table
             v
             (λ (w) (+ w (exp (- ll top))))
             0.0))
        samples)
      (let1 (total (hash-table-fold table (λ (v w acc) (+ acc w)) 0.0))
            (histogram-sort
              (map (Λ ((,v unquote w)) (cons v (/ w total)))
                   (hash-table->alist table))))))
  (define (node-signature n)
    (list (node-addr n)
          (node-kind n)
          (node-role n)
          (map node-addr (vector->list (node-parents n)))
          (map (Λ ((,entry unquote polarity))
                  (cons (node-addr entry) polarity))
               (node-scope n))))
  (define (same-built-value? a b)
    (cond ((and (deferred? a) (deferred? b))
           (same-value? (deferred-args a) (deferred-args b)))
          ((or (deferred? a) (deferred? b)) #f)
          (else (same-value? a b))))
  (define (first-mismatch same? ch ch*)
    (let loop ((a 1))
      (and (<= a (chain-count ch))
           (if (same? (chain-node ch a) (chain-node ch* a))
             (loop (add1 a))
             a))))
  (define (construction-check
           model
           #!key
           (seed 17)
           (rng #f)
           (semantics 'upstream))
    (let1 (src (or rng (make-stdgen-source seed)))
          (receive
            (ch result)
            (build model (rng-source-copy src) semantics 'check)
            (if (or (not result) (rejected-ll? (chain-llcum ch)))
              'skipped
              (receive
                (ch* result*)
                (build model (rng-source-copy src) semantics 'check)
                (rebuild-check ch result ch* result*)
                (redraw-check ch (rng-source-copy src))
                #t)))))
  (define (rebuild-check ch result ch* result*)
    (define (differ what . args)
      (apply hakaru10-error
             'internal
             'check
             (string-append "a rebuild and the initial trace differ in " what)
             args))
    (unless
      (and result*
           (= (chain-count ch) (chain-count ch*))
           (= (node-addr result) (node-addr result*)))
      (differ "graph" (chain-count ch) (and result* (chain-count ch*))))
    (cond ((first-mismatch
             (λ (n n*) (equal? (node-signature n) (node-signature n*)))
             ch
             ch*)
           =>
           (λ (a) (differ "graph" a)))
          ((first-mismatch
             (λ (n n*) (same-built-value? (node-value n) (node-value n*)))
             ch
             ch*)
           =>
           (λ (a)
              (differ
                "value"
                a
                (node-value (chain-node ch a))
                (node-value (chain-node ch* a)))))
          ((first-mismatch
             (λ (n n*)
                (ll-close?
                  (nstate-ll (node-state n))
                  (nstate-ll (node-state n*))))
             ch
             ch*)
           =>
           (λ (a) (differ "LL" a)))
          ((not (ll-close? (chain-llcum ch) (chain-llcum ch*)))
           (differ "LL" (chain-llcum ch) (chain-llcum ch*)))))
  (define (redraw-check ch src)
    (define (differ what . args)
      (apply hakaru10-error
             'internal
             'check
             (string-append
               "an address-order redraw and the initial trace differ in "
               what)
             args))
    (match/first
      (chain-fold
        (Λ (,n (,ll unquote scale))
           (cond ((resampleable? n)
                  (receive
                    (x llx)
                    (distk-sample (node-distk n) src)
                    (unless
                      (same-value? x (node-value n))
                      (differ "value" (node-addr n) x (node-value n)))
                    (cons (+ ll llx) (+ scale (abs llx)))))
                 ((eq? (node-kind n) 'observed)
                  (let ((llo (nstate-ll (node-state n)))
                        (inactive? (node-inactive? n)))
                    (cons (if inactive? ll (+ ll llo))
                          (if (and inactive? (extended? ch))
                            scale
                            (+ scale (abs llo))))))
                 (else (cons ll scale))))
        '(0.0 . 0.0)
        ch)
      ((,ll unquote scale)
       (let1 (llcum (chain-llcum ch))
             (unless
               (or (nan? llcum) (ll-close? ll llcum scale))
               (differ "LL" ll llcum))))))
  (define (resampleable? n) (eq? (node-kind n) 'resampleable))
  (define (node-distk n)
    (let1 (fn (node-fn n))
          (if (distk? fn) fn (fn (leaf-values (node-parents n))))))
  (define (recomputed-state n ts #!optional (v (node-value n)))
    (if (eq? (node-role n) 'exit)
      (make-nstate
        (let1 (v (node-value (branch-active-result (node-branch n))))
              (if (node-inactive? n) v (force-value v)))
        0.0
        #f
        ts)
      (let* ((dk (node-distk n)) (kind (distk-kind dk)) (rd (distk-rd dk)))
        (unless
          (eq? kind (node-kind n))
          (hakaru10-error
            'construction
            'check
            "a distribution constructor changed the kind of its node"
            n
            (node-kind n)
            kind))
        (case kind
          ((dirac)
           (make-nstate
             (let1 (x (distk-value dk))
                   (if (node-inactive? n) x (force-value x)))
             0.0
             #f
             ts))
          ((observed)
           (let1 (obs (distk-value dk))
                 (check-observation n obs)
                 (make-nstate obs ((rdistr-log-density rd) obs) rd ts)))
          (else (make-nstate v ((rdistr-log-density rd) v) rd ts))))))
  (define (scope-inactivity n)
    (count (Λ ((,entry unquote polarity))
              (not (eq? (node-value entry) polarity)))
           (node-scope n)))
  (define (same-rdistr? a b)
    (if (and a b)
      (and (eq? (rdistr-name a) (rdistr-name b))
           (same-value? (rdistr-params a) (rdistr-params b)))
      (eq? a b)))
  (define (reference-check ch)
    (define (fail msg n . args)
      (apply hakaru10-error 'internal 'check msg (node-addr n) args))
    (define (check-state n s)
      (let1 (s* (recomputed-state n (nstate-tstamp s) (nstate-val s)))
            (unless
              (same-value? (nstate-val s) (nstate-val s*))
              (fail "a value differs from its recomputation"
                    n
                    (nstate-val s)
                    (nstate-val s*)))
            (unless
              (same-rdistr? (nstate-dst s) (nstate-dst s*))
              (fail "a distribution differs from its recomputation"
                    n
                    (nstate-dst s)
                    (nstate-dst s*)))
            (unless
              (ll-close? (nstate-ll s) (nstate-ll s*))
              (fail "an LL differs from its recomputation"
                    n
                    (nstate-ll s)
                    (nstate-ll s*)))))
    (let ((now (chain-now ch)) (every-node? (extended? ch)))
      (chain-fold
        (λ (n _)
           (let ((s (node-state n)) (inactive (node-inactive n)))
             (unless
               (= inactive (scope-inactivity n))
               (fail "a deactivation count differs from its recomputation"
                     n
                     inactive
                     (scope-inactivity n)))
             (when (and (node-delayed n) (or every-node? (zero? inactive)))
                   (fail "an update is delayed on an active node or in 'extended mode"
                         n))
             (when (or (node-pending n) (node-queued n))
                   (fail "a node is still pending or queued after the step" n))
             (when (> (nstate-tstamp s) now)
                   (fail "a tstamp is after now" n (nstate-tstamp s) now))
             (when (or every-node? (zero? inactive)) (check-state n s))))
        (void)
        ch)
      (let1 (card (- (count node-inactive? (chain-sampleable ch))))
            (unless
              (= (chain-card-change ch) card)
              (hakaru10-error
                'internal
                'check
                "the card change differs from its recomputation"
                (chain-card-change ch)
                card)))
      #t))
  (define (resampleable-nodes ch) (reverse (chain-sampleable ch)))
  (define (load-state! ch xs)
    (let* ((now (chain-now ch))
           (rest (chain-fold
                   (λ (n xs)
                      (node-inactive-set! n (scope-inactivity n))
                      (node-state-set!
                        n
                        (if (resampleable? n)
                          (if (pair? xs)
                            (recomputed-state n now (car xs))
                            (hakaru10-error
                              'construction
                              'load-state!
                              "too few values"
                              n))
                          (recomputed-state n now)))
                      (node-delayed-set! n #f)
                      (node-pending-set! n #f)
                      (if (resampleable? n) (cdr xs) xs))
                   xs
                   ch)))
      (unless
        (null? rest)
        (hakaru10-error 'construction 'load-state! "too many values" rest))
      (chain-card-change-set!
        ch
        (- (count node-inactive? (chain-sampleable ch))))))
  (define (ext-states ch #!key (max-states 100000))
    (let ((now (chain-now ch)) (last (chain-count ch)) (found 0))
      (reverse
        (let walk ((a 1) (prefix '()) (states '()))
          (if (> a last)
            (begin
              (add1! found)
              (when (> found max-states)
                    (hakaru10-error
                      'support
                      'ext-states
                      "more states than max-states"
                      max-states))
              (cons (reverse prefix) states))
            (let1 (n (chain-node ch a))
                  (node-inactive-set! n (scope-inactivity n))
                  (if (resampleable? n)
                    (fold (Λ ((,x unquote p) ,states)
                             (if (positive? p)
                               (begin
                                 (node-state-set! n (recomputed-state n now x))
                                 (walk (add1 a) (cons x prefix) states))
                               states))
                          states
                          (choice-support (node-distk n) 'ext-states))
                    (begin
                      (node-state-set! n (recomputed-state n now))
                      (walk (add1 a) prefix states)))))))))
  (define (forced-step-log-alpha ch n x)
    (when (or (not (resampleable? n)) (node-inactive? n))
          (hakaru10-error
            'internal
            'forced-step-log-alpha
            "an active resampleable node is expected"
            n))
    (journal-begin! ch)
    (chain-now-set! ch (add1 (chain-now ch)))
    (chain-llcum-set! ch 0.0)
    (let* ((card-old (chain-card-change ch))
           (s (node-state n))
           (ll ((rdistr-log-density (nstate-dst s)) x))
           (fb (apply-proposal! n x ll (- ll (nstate-ll s))))
           (delta (begin (propagate! ch) (chain-llcum ch)))
           (ratio (if (rejected-ll? delta)
                    -inf.0
                    (log-acceptance-ratio
                      ch
                      (vector-length (chain-samp ch))
                      card-old
                      fb))))
      (journal-rollback! ch)
      ratio))
  (define (kernel-residual
           model
           #!key
           (seed 17)
           (max-states 100000)
           (semantics 'extended))
    (receive
      (ch result)
      (build model (make-stdgen-source seed) semantics 'kernel-residual)
      (unless
        result
        (hakaru10-error
          'construction
          'kernel-residual
          "the model's first build was rejected"))
      (let* ((nodes (resampleable-nodes ch))
             (states (ext-states ch #:max-states max-states))
             (log-weights
               (map (λ (xs) (load-state! ch xs) (chain-extended-ll ch))
                    states))
             (top (let1 (top (fold (λ (l top) (if (finite? l) (max l top) top))
                                   -inf.0
                                   log-weights))
                        (if (finite? top)
                          top
                          (hakaru10-error
                            'construction
                            'kernel-residual
                            "no state of the model has a positive finite weight"
                            top))))
             (weights
               (map (λ (l) (if (finite? l) (exp (- l top)) 0.0)) log-weights))
             (z (fold + 0.0 weights))
             (π (make-hash-table equal?))
             (πT (make-hash-table equal?)))
        (define (flow! xs mass)
          (hash-table-update!/default πT xs (λ (m) (+ m mass)) 0.0))
        (for-each
          (λ (xs w)
             (hash-table-update!/default π xs (λ (p) (+ p (/ w z))) 0.0))
          states
          weights)
        (hash-table-walk
          π
          (λ (xs p)
             (when (positive? p)
                   (load-state! ch xs)
                   (let* ((active
                            (filter-map
                              (λ (n i)

              (dist (condition #t bern) 0.3))
         (dist (condition #t bern) 0.6))
    (return x)))

hakaru10.scm runs the kernel residual on five more models, next to their other checks: act-update and act-update/finite (case B4), whose step activates an observation and updates its parameters at once, and guarded-car, guarded-car/reversed and nested-guarded-car (case B6), whose inactive branches hold a deferred Dirac value.

A state with no active resampleable node stays put (deviation 6): the residual is 0 on a model whose only choice sits in a branch never taken. A support with duplicate points gives a value the weight of all its points, as the sampler does: the residual of uniformly '(1 1 2), whose 1 weighs 2/3, is below 10⁻¹².

As a positive control, the residual exceeds 10⁻³ (it is about .063) on a model whose liar declares a support that disagrees with its density, so that its proposal is not the one the acceptance ratio assumes.

(define (liar)
  (make-distribution
    'liar
    #:log-density
    (λ (x) (log (if x 0.9 0.1)))
    #:sample
    (λ (src)
       (let1 (x (< (rng-double! src 0.0 1.0) 0.9))
             (values x (log (if x 0.9 0.1)))))
    #:support
    (τ '((#t . 0.5) (#f . 0.5)))))

(define liar-or
  (do/monad
    (← a (dist liar))
    (← b (dist bern 0.3))
    (dist (condition #t bern) (lift (λ (av bv) (if (or av bv) 0.8 0.2)) a b))
    (return a)))

A state whose extended LL is NaN or +inf weighs nothing, as exact enumeration prunes it (E6) and no step enters it: the residual is that of the other states. It is still positive on liar-or/nan, the liar next to nan-path's choice, and below 10⁻¹² on nan-path and on plus-inf-state, whose b = 1 has LL +inf and whose posterior is 2/3 and 1/3 on b = 2 and 3.

(define liar-or/nan
  (do/monad
    (← a (dist liar))
    (← b (dist bern 0.3))
    (dist (condition #t bern) (lift (λ (av bv) (if (or av bv) 0.8 0.2)) a b))
    (← k (dist uniformly '(0 1 2)))
    (dist (condition 0.0 normal) 0.0 (lift exact->inexact k))
    (return a)))

(define plus-inf-state
  (do/monad
    (← b (dist uniformly '(1 2 3)))
    (dist (condition 0.0 uniform)
          0.0
          (lift (λ (bv) (case bv ((1) 0.0) ((2) 1.0) (else 2.0))) b))
    (return b)))

With #:semantics 'upstream the kernel is upstream's, whose step delays the updates of inactive nodes (Metropolis.hs:298-303), run from the states where no update is delayed. On pswitch its residual is .05, while the extended kernel's is below 10⁻¹²: the reactivation bias of E8, seen in one step.

T is the independence proposal's (Distribution.hs:29-32), the default kernel: a choice whose distribution has another kernel, such as bern/flip's flip (Distribution.hs:64-70), is a support error, since T would not describe the engine's step. A model where no state has a positive weight, here one that observes #t from bern 0, has no target π: a construction error.
