Introduction

This section tests the maybe monad, where (just . v) is a computation that succeeded with the value v and the empty list is a computation that failed, short-circuiting every later bind.

Implementation

(module
  (aux category maybe)
  *
  (import scheme (chicken base) (aux base))
  (define (return v) `(just unquote v))
  (define (>>= m f) (match/first m ((just unquote v) (f v)) (else '())))
  (define (fail . args) '()))

test/bind: pass

A failure anywhere in the block makes the whole block fail. 
(define (test/bind _)
  (⊦= '(just . 3) (do/monad (← x ,1) (← y (return 2)) ,(+ x y)))
  (⊦= '() (do/monad (← x ,1) (← y (fail)) ,(+ x y))))

test/return: pass

return takes exactly one value, like in every other monad instance. 
(define (test/return _)
  (let ((arity-error?
          (λ args
             (condition-case
               (begin (apply return args) #f)
               (e (exn arity) #t)))))
    (⊨ (arity-error? 1 2 3))
    (⊨ (arity-error?))))
