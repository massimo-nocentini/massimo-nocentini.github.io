Introduction

This section tests the state monad, Haskell's State s a, where a computation is a transition from a state to the pair of its result and the next state, Haskell's (a, s) tuple; binding threads the state from one computation to the next, strictly, as Haskell's Control.Monad.State.Strict does.

Implementation

A computation is a category-state record around its transition, the image of Haskell's newtype, so that a computation is a type of its own and not any procedure; run-state applies the transition to a state.

(module
  (aux category state)
  *
  (import scheme (chicken base) (aux base))
  (define-record category-state run)
  (set-record-printer! category-state (λ (m port) (display "#<state>" port)))
  (define (run-state m s) ((category-state-run m) s))
  (define (eval-state m s) (car (run-state m s)))
  (define (exec-state m s) (cdr (run-state m s)))
  (define (return v) (make-category-state (λ (s) (cons v s))))
  (define (>>= m f)
    (make-category-state
      (λ (s) (let1 (r (run-state m s)) (run-state (f (car r)) (cdr r))))))
  (define (fail . args)
    (make-category-state
      (λ (s)
         (error "State monad does not support failure"
                `((on ,s) (args unquote args))))))
  (define get (make-category-state (λ (s) (cons s s))))
  (define (put s) (make-category-state (λ (_) (cons (void) s))))
  (define (modify f) (make-category-state (λ (s) (cons (void) (f s)))))
  (define (gets f) (make-category-state (λ (s) (cons (f s) s))))
  (define (state f) (make-category-state f))
  (define (with-state f m) (make-category-state (λ (s) (run-state m (f s))))))

test/get-put: pass

test/laws: pass

The left identity, right identity and associativity laws hold on every state they are run on. 
(define (test/laws _)
  (let ((f (λ (x) (do/monad (modify (λ (s) (cons x s))) ,(* 2 x))))
        (g (λ (y) (do/monad (← s get) (put (list y s)) ,(+ y 1))))
        (m (do/monad (← s get) (put (cons 'm s)) ,(length s))))
    (for-each
      (λ (s0)
         (⊦= (run-state (f 5) s0) (run-state (>>= (return 5) f) s0))
         (⊦= (run-state m s0) (run-state (>>= m return) s0))
         (⊦= (run-state (>>= (>>= m f) g) s0)
             (run-state (>>= m (λ (x) (>>= (f x) g))) s0)))
      '(() (a) (a b c)))))

test/strict: pass

Building a computation runs nothing; running (>>= m f) runs m before f is applied to its result, as the strict state monad does. 
(define (test/strict _)
  (let* ((log '())
         (m (do/monad
              (← a (state (λ (s) (set! log (cons 'm log)) (cons 1 s))))
              (let _ (set! log (cons 'f log)))
              ,a)))
    (⊦= '() log)
    (⊦= '(1 . s) (run-state m 's))
    (⊦= '(f m) log)))

test/fail: pass

A value that does not match the pattern of a ← clause goes to fail, which raises an error when the computation runs, as Haskell's fail msg = error msg does, and not when it is built. 
(define (test/fail _)
  (let* ((m (do/monad (← (,a unquote b) ,'()) ,a))
         (message
           (condition-case
             (begin (run-state m 's) #f)
             (e (exn) ((condition-property-accessor 'exn 'message) e)))))
    (⊨ (category-state? m))
    (⊨ (and (string? message)
            (substring-index "State monad does not support failure" message)
            #t))
    (⊨ (category-state? (fail 'x)))
    (⊦raises (exn) (run-state (fail 'x) 's))))

test/long-chain: pass

Chains of a hundred thousand binds run, nested to the right as the traversals build them and to the left as a fold over >>= does. 
(define (test/long-chain _)
  (let* ((n 100000)
         (sum (quotient (* n (- n 1)) 2))
         (left (fold (λ (i m) (>>= m (λ (_) (modify (λ (s) (+ s i))))))
                     (return (void))
                     (iota n))))
    (⊦= sum
        (exec-state
          (for-each/monad (λ (i) (modify (λ (s) (+ s i)))) (iota n))
          0))
    (⊦= sum (exec-state left 0))
    (⊦= n (length (eval-state (replicate/monad n tick) 0)))))

test/representation: pass

A computation is a category-state record, as Haskell's newtype makes State s a a type of its own: a procedure, even one shaped as a transition, is not a computation. run-state does not check its argument, so running a value that is not a computation raises CHICKEN's own error for a record of the wrong type, the cheapest outcome. 
(define (test/representation _)
  (⊨ (category-state? (do/monad (← x get) (return x))))
  (⊨ (not (category-state? (λ (s) (cons 1 s)))))
  (⊦raises (exn type) (run-state 42 0)))

test/traversals: pass

The traversals run their computations left to right, the head first, so effects on the state happen in list order, as Haskell's mapM, sequence, replicateM, mapM_ and foldM do. 
(define (test/traversals _)
  (⊦= '(((a . 0) (b . 1) (c . 2)) . 3)

        (traverse/monad (λ (x) (<$> (cut cons x <>) tick)) '(a b c))

  (⊦= '(() . s) (run-state (traverse/monad (λ (x) tick) '()) 's))
  (⊦= '((0 1 2) . 3) (run-state (replicate/monad 3 tick) 0))

test/list->monad-is-not-sequence: pass

list->monad is return of the mconcat of a pure list, not Haskell's sequence: given a list of computations it answers that very list, unrun, and leaves the state as it is. To run a list of computations, use sequence/monad. 
(define (test/list->monad-is-not-sequence _)
  (⊦= '((1 2) . 0) (run-state (list->monad '(1 2)) 0))
  (⊦= '(1 2) (eval-state (list->monad '(1 2)) 0))
  (let1 (r (run-state (list->monad (list tick tick)) 0))
        (⊦= 0 (cdr r))
        (⊨ (and (= 2 (length (car r))) (every category-state? (car r)))))
  (⊦= '((0 1) . 2) (run-state (sequence/monad (list tick tick)) 0)))
