Utilities

Helpers to summarize the samples of a chain, after Util.hs of Embedded probabilistic domain-specific language Hakaru10, November 2016. A chain of mcmC is a list of samples; these procedures reduce it to a histogram, to its first two moments, or to the Kullback-Leibler divergence from another histogram, which is how the paper compares a model with its exact distribution (P §2.1 p.6-7, l.282-327).

A histogram is an alist ((key . mass) ...) sorted ascending, standing for Haskell's type Histogram = M.Map Double Double (U:25), whose M.toList is ascending too. Where Haskell orders keys by the Ord class, the port uses one total order over Scheme values, generic<?: booleans, then numbers, characters, strings, symbols, lists and vectors, each ordered in the obvious way (#f before #t, lists lexicographically, vectors as the lists of their elements).

The floating-point folds are those of the Haskell code, in the same direction, so that the KL divergences and moments recorded upstream are reproduced bit for bit: sum is a left fold, the variance and the insertions of tabulate are right folds, kl folds the keys of p in ascending order. The moments are

x̄ = (1/n) Σᵢ₌₁ⁿ xᵢ, σ² = (1/(n − 1)) Σᵢ₌₁ⁿ (xᵢ − x̄)²

and the divergence of q from the theoretical p (U:47-50) is

KL(p ‖ q) = Σᵢ pᵢ log (pᵢ / qᵢ)

which is undefined, and raises an (exn hakaru10) condition of kind support, where qᵢ = 0 < pᵢ.

(module
  (aux hakaru10 util)
  *
  (import
    scheme
    (chicken base)
    (chicken sort)
    (chicken flonum)
    (only (chicken string) ->string)
    (only srfi-1 count)
    srfi-69
    (aux base)
    (only (aux hakaru10 distribution) hakaru10-error))
  (define generic-orders
    (list (cons boolean? (λ (a b) (and (not a) b)))
          (cons number?
                (λ (a b)
                   (cond ((not (and (real? a) (real? b)))
                          (generic<?
                            (list (real-part a) (imag-part a))
                            (list (real-part b) (imag-part b))))
                         ((= a b) (and (exact? a) (inexact? b)))
                         (else (< a b)))))
          (cons char? char<?)
          (cons string? string<?)
          (cons symbol?
                (λ (a b) (string<? (symbol->string a) (symbol->string b))))
          (cons (λ (v) (or (null? v) (pair? v)))
                (λ (a b)
                   (cond ((null? a) (pair? b))
                         ((null? b) #f)
                         ((generic<? (car a) (car b)) #t)
                         ((generic<? (car b) (car a)) #f)
                         (else (generic<? (cdr a) (cdr b))))))
          (cons vector?
                (λ (a b) (generic<? (vector->list a) (vector->list b))))))
  (define (generic-order v)
    (let loop ((rank 0) (orders generic-orders))
      (cond ((null? orders) (values rank (λ (a b) #f)))
            (((caar orders) v) (values rank (cdar orders)))
            (else (loop (add1 rank) (cdr orders))))))
  (define (generic<? a b)
    (let-values
      (((ra less?) (generic-order a)) ((rb _) (generic-order b)))
      (or (< ra rb) (and (= ra rb) (less? a b)))))
  (define (histogram-sort alist)
    (sort alist (λ (p q) (generic<? (car p) (car q)))))
  (define (hash-table->histogram table)
    (histogram-sort (hash-table->alist table)))
  (define (hist xs)
    (let1 (table (make-hash-table equal?))
          (for-each (λ (x) (hash-table-update!/default table x add1 0)) xs)
          (hash-table->histogram table)))
  (define (frequency pred xs)
    (fp/ (exact->inexact (count pred xs)) (exact->inexact (length xs))))
  (define (momenta xs)
    (let* ((xs (map exact->inexact xs))
           (n (exact->inexact (length xs)))
           (av (fp/ (foldl fp+ 0.0 xs) n))
           (sqr (λ (x) (fp* x x))))
      (cons av
            (fp/ (foldr (λ (x acc) (fp+ (sqr (fp- x av)) acc)) 0.0 xs)
                 (fp- n 1.0)))))
  (define (to-bin step x)
    (let1 (b (fpfloor (fp/ x step))) (fp* (if (fp= b 0.0) 0.0 b) step)))
  (define (tabulate step xs)
    (let* ((step (exact->inexact step))
           (quantum (fp/ 1.0 (exact->inexact (length xs))))
           (insert!
             (λ (x table)
                (hash-table-update!/default
                  table
                  (to-bin step (exact->inexact x))
                  (λ (old) (fp+ quantum old))
                  0.0)
                table)))
      (hash-table->histogram (foldr insert! (make-hash-table equal?) xs))))
  (define (tabulate/bins nbins xs)
    (let* ((ys (map exact->inexact xs))
           (mn (foldl fpmin (car ys) (cdr ys)))
           (mx (foldl fpmax (car ys) (cdr ys)))
           (step-raw
             (if (fp= mn mx) 1.0 (fp/ (fp- mx mn) (exact->inexact nbins)))))
      (tabulate (fpexpt 10.0 (round (fp/ (fplog step-raw) (fplog 10.0)))) ys)))
  (define (kl p q)
    (let1 (q (alist->hash-table q equal?))
          (foldl (Λ (,sum (,i unquote pi))
                    (let1 (qi (hash-table-ref
                                q
                                i
                                (τ (hakaru10-error
                                     'support
                                     'kl
                                     (string-append
                                       "Undefined KL divergence - q is 0 when p is not at point "
                                       (->string i))
                                     i))))
                          (+ sum (* pi (log (/ pi qi))))))
                 0.0
                 (histogram-sort p))))
  (define (plot h #!optional (path "/tmp/plot.dat"))
    (with-output-to-file
      path
      (τ (print "x  y")
         (for-each (Λ ((,k unquote v)) (print k " " v)) (histogram-sort h))))
    path))

-- compute the first two momenta
momenta :: [Double] -> (Double,Double)
momenta lst = (av,sigma2)

-- Tabulate with the given bin size
tabulate :: Double -> [Double] -> Histogram
tabulate step lst =
  foldr (\x -> M.insertWith' (+) (to_bin x) quantum) M.empty lst

U4. tabulate/bins, that is tabulate', takes only a hint of the number of bins: the bin size is rounded to a power of ten.

-- The argument is the _hint_ to the number of bins
tabulate' :: Int -> [Double] -> Histogram
tabulate' nbins lst =
  foldr (\x -> M.insertWith' (+) (to_bin x) quantum) M.empty lst
 where
   mn = minimum lst
   mx = maximum lst
   quantum = 1 / fromIntegral (length lst)
   step_raw = if mn == mx then 1 else (mx - mn) / fromIntegral nbins
   step  = 10.0 ** (fromInteger . round $ log step_raw / log 10)
   to_bin x = fromInteger (floor (x / step)) * step

test/kl: pass

U5. kl is the Kullback-Leibler divergence KL(p ‖ q); the bins of q need not be sorted, those absent from p do not count, and of a repeated bin of q the first one counts, as with assoc:

kl :: Histogram -> Histogram -> Double
kl p q = M.foldlWithKey' f 0 p
 where f sum i pi | Just qi <- M.lookup i q = sum + pi * log (pi / qi)
                  | otherwise =
         error $ "Undefined KL divergence - q is 0 when p is not at point " ++
                 show i

cf. U:51-56; the expected value 0.14384103622589 is ½ log 2 + ½ log ⅔ summed in this order.
