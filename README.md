# massimo-nocentini.github.io

Massimo Nocentini's papers, notes, memos and source code, published at
<https://massimo-nocentini.github.io/>.

The site is a [Hugo](https://gohugo.io) site in `hugo/`, set with the author's own theme
[tufte.hugo](https://github.com/massimo-nocentini/tufte.hugo) (Tufte CSS, and the Tufte-LaTeX handout and
book classes at HTML level). GitHub Actions builds and deploys it on every push to `master`.

## Contents

| Path | What |
|---|---|
| `hugo/content/post/` | The posts: papers and books read, notes, releases, the Scheme test suites (61 files) |
| `hugo/content/book/` | Four books, each a tufte.hugo book generated by its own repository (below) |
| `hugo/content/page/` | Standalone pages, tufte handouts (`«Simone, mi ami tu?»`, Luigi Giussani) |
| `hugo/content/about.md`, `archives.md`, `search.md`, `author/` | The CV, the archives, the search page, the authors taxonomy |
| `hugo/test-suites/` | The HTML reports of the Scheme test suites, included by their posts (`make import-test-suites`) |
| `hugo/data/bibliography.yaml` | The bibliography the posts cite |
| `hugo/assets/css/` | `site.css` (every page) and one stylesheet per book, loaded only on its pages (`layouts/_partials/head_custom.html`) |
| `hugo/layouts/_shortcodes/` | Site shortcodes (`github`, `docker`, `include`) and the books' own (`dtb-*`, `ccc-*`, `bj-*`, `cir-*`) |
| `hugo/themes/tufte.hugo/` | The theme, a git submodule; its `README.md` is the manual of every front-matter key and shortcode |
| `PhD/`, `UniFI-Python-Spring-2020/` | Talks and slides of the PhD years and of a 2020 Python course, kept in the repository (not part of the Hugo site) |
| `index.md.old`, `compose.yml`, `id_rsa.pub` | The pre-Hugo home page, the Docker Compose services of the pre-Hugo site (test suites, index), the public SSH key |

### The books

Each book is generated, not edited by hand: its Markdown files say so in their front matter, and its
generator checks that nothing of the source is lost.

| Book (`hugo/content/book/`) | Generated by |
|---|---|
| `dizionario-di-teologia-biblica` — X. Léon-Dufour, *Dizionario di Teologia Biblica* | `massimo-nocentini/dufour.tex`: `tools/dufour` |
| `catechismo-della-chiesa-cattolica` — *Catechismo della Chiesa Cattolica* and its *Compendio* | `massimo-nocentini/catechismo.tex`: `tools/hugo` |
| `bibbia-di-gerusalemme` — *La Bibbia di Gerusalemme* | `massimo-nocentini/bibbia-gerusalemme.tex`: `tools/hugo` |
| `cirillo-di-gerusalemme-le-catechesi` — Cirillo di Gerusalemme, *Le catechesi* | `massimo-nocentini/cirillo-catechesi.tex`: `tools/hugo` |

The Bible references of the other books, and of some pages, link to the verses of the Bibbia di Gerusalemme.

## Building

The theme needs the latest Hugo release, standard edition (0.169.0 or newer). Clone with the submodule:

```sh
git clone --recurse-submodules git@github.com:massimo-nocentini/massimo-nocentini.github.io.git
cd massimo-nocentini.github.io/hugo
make serve      # hugo serve -D --gc: the site, drafts included, at http://localhost:1313/
make build      # the production build into hugo/public/ (git-ignored), as the deploy does it
```

A full build takes about two minutes, most of it for the Bible.

## Deploying

`.github/workflows/pages.yml` installs the latest Hugo release (checked against its checksums), builds
`hugo/` with `hugo --gc --minify` and deploys `hugo/public` to GitHub Pages on every push to `master`
(the repository's Pages source is "GitHub Actions"). Pull requests are built but not deployed. A page
with `draft: true` is left out of the production build.
